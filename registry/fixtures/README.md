# Deterministic seed fixtures

This directory contains exactly 50 schema-valid local fixtures generated from their numeric IDs. They are **not** official or community packages and make no upstream provenance claims. The fixtures exist to exercise catalog indexing and CI validation until real submissions with verifiable source URLs, licenses, signatures, and SHA-256 artifacts are available.

Regenerate deterministically with the repository generator procedure in CI; do not publish these entries as installable packages.
